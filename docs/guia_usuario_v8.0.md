# CYMATIC STUDIO v8.0 · Quantum Bloom
## Guía de Usuario – Versión PRO

---

### 📋 Introducción

**CYMATIC STUDIO v8.0 "Quantum Bloom"** es la versión profesional de nuestro motor de visualización musical. Incluye 5 geometrías sagradas, 5 paletas de color, efecto Bloom, exportación de fotogramas y grabación de video.

---

### 🖥️ Requisitos del Sistema

- **Navegador:** Chrome 120+, Edge 120+
- **Conexión a Internet:** Necesaria para cargar librerías CDN
- **GPU:** WebGL 2.0 con soporte para shaders
- **Espacio en disco:** 10 MB (archivo HTML)

---

### 🔑 Activación de Licencia

1. Adquiere tu licencia en [checkout.html](checkout.html).
2. Recibirás una clave de licencia por correo.
3. Al abrir el archivo, ingresa la clave en el campo correspondiente.
4. La licencia se activará automáticamente.

---

### 🎮 Controles Interactivos

| Acción | Efecto |
| :--- | :--- |
| **Mover el cursor** | Distorsiona las ondas cimáticas |
| **Tecla 1-5** | Cambia entre 5 modos de geometría |
| **Tecla Q** | Activa/Desactiva el modo cuántico |
| **Tecla G** | Activa/Desactiva el efecto Glitch |
| **Tecla T** | Activa/Desactiva el modo Tormenta |
| **Tecla C** | Dispara una onda de choque |
| **Tecla Espacio** | Genera un cristal interactivo |
| **Tecla P** | Captura la pantalla en PNG |
| **Botón "🎬 Grabar Video"** | Graba un clip WebM de 10 segundos |
| **Botón "📸 Frames"** | Exporta una secuencia de PNGs |

### ❓ Solución de Problemas

**La licencia no se activa:**  
→ Verifica que la clave tenga el formato correcto (CYMATIC-XXXXXX).  
→ Asegúrate de estar conectado a Internet.  
→ Contacta a soporte si el problema persiste.

**El video grabado no tiene audio:**  
→ Asegúrate de que el micrófono o sintetizador estén activos.  
→ Verifica que el navegador permita captura de audio.
