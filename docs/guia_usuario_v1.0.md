# CYMATIC STUDIO v1.0 · Quantum Seed
## Guía de Usuario – Versión Gratuita

---

### 📋 Introducción

**CYMATIC STUDIO v1.0 "Quantum Seed"** es la versión gratuita de nuestro motor de visualización musical cuántica. Esta versión te permite experimentar los conceptos básicos de la geometría sagrada y la cimática interactiva.

---

### 🖥️ Requisitos del Sistema

- **Navegador:** Chrome 120+, Edge 120+, Firefox 120+
- **Conexión a Internet:** Necesaria para cargar librerías CDN
- **Hardware:** GPU con soporte WebGL 2.0 (recomendado)
- **Sistema Operativo:** Windows, macOS, Linux

---

### 🚀 Instalación

1. Descarga el archivo `cymatic_v1.0.html`.
2. Ábrelo en tu navegador Chrome/Edge.
3. La demo se ejecutará automáticamente.
4. No requiere instalación adicional.

---

### 🎮 Controles Interactivos

| Acción | Efecto |
| :--- | :--- |
| **Mover el cursor** | Distorsiona las ondas cimáticas en tiempo real |
| **Clic en cualquier lugar** | Reinicia el motor de audio (si está activo) |
| **Tecla 1, 2, 3** | Cambia entre los 3 modos de geometría |
| **Botón "🎤 Micrófono"** | Activa el micrófono para visualizar tu voz |
| **Botón "♪ Sintetizador"** | Activa el sintetizador integrado |

---

### 🌀 Modos de Geometría

| Modo | Descripción |
| :--- | :--- |
| **1D Chladni** | Patrones de ondas estacionarias en placas |
| **2D Toroide** | Flujo helicoidal basado en la proporción áurea |
| **3D Metatrón** | Vértices hiper-dimensionales interconectados |

---

### ❓ Solución de Problemas

**El canvas no se ve:**  
→ Verifica que tu navegador soporte WebGL.  
→ Actualiza el navegador a la última versión.

**El micrófono no funciona:**  
→ Asegúrate de dar permisos de acceso al micrófono.  
→ Reinicia el navegador y vuelve a intentarlo.

**Rendimiento bajo:**  
→ Reduce el número de líneas en el slider "Complejidad".  
→ Cierra otras pestañas o aplicaciones pesadas.
