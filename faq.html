❓ Preguntas Frecuentes

Todo lo que necesitas saber sobre CYMATIC STUDIO.

¿Cómo recibo mi producto después de pagar?

Recibirás un correo electrónico con un enlace de descarga directa para tu versión. Si elegiste pago manual, el envío se realiza en un plazo máximo de 24 horas después de verificar el pago.

¿Qué incluye la licencia?

La licencia te da acceso perpetuo a la versión adquirida, incluyendo actualizaciones menores durante 1 año. La licencia Enterprise incluye marca blanca y soporte prioritario.

¿Puedo usar el software en varios dispositivos?

Sí. La licencia PRO permite hasta 2 dispositivos, ULTRA hasta 3, y Enterprise uso ilimitado en dispositivos de tu organización.

¿Qué es la "marca blanca"?

Con la licencia Enterprise, puedes reemplazar el logo "CYMATIC STUDIO" por el tuyo propio, cambiar los colores de la interfaz y personalizar el nombre del producto para tu marca.

¿El código está protegido contra copia?

Sí. Cada archivo incluye un sistema de verificación de licencia que bloquea el acceso si no se detecta una clave válida. El código está ofuscado para dificultar su modificación y redistribución.

¿Qué navegadores son compatibles?

Chrome 120+, Edge 120+, Firefox 120+, Opera 100+. Recomendamos Chrome para un rendimiento óptimo con Web Audio API y Three.js.

¿Puedo obtener un reembolso?

Sí, ofrecemos una garantía de devolución de 30 días si el producto no funciona como se describe en la documentación.
